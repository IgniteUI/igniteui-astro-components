# Typography

The type scale and text styling applied by the documentation theme. All examples below reflect exactly what you will see in your `.md` and `.mdx` files.

## Headings

Six levels of section headings. Choose the level based on document structure — not visual size.

| Element | Use when |
|---|---|
| `<h1>` | The single top-level title of the page. One per page. |
| `<h2>` | Major sections directly beneath the page title. |
| `<h3>` | Sub-sections within an `<h2>` section. |
| `<h4>` | Sub-sections within an `<h3>`, for deeper nesting. |
| `<h5>` | Rarely needed — deep nesting usually signals restructuring. |
| `<h6>` | Deepest level; use only when six distinct levels are genuinely required. |

**Markdown syntax:**

```md
# Heading level 1 — page title, one per page
## Heading level 2 — major section
### Heading level 3 — sub-section
#### Heading level 4 — deeper sub-section
##### Heading level 5 — avoid unless strictly necessary
###### Heading level 6 — deepest level
```

**Rendered result:**

<h1>Heading level 1 — page title, one per page</h1>
<h2>Heading level 2 — major section</h2>
<h3>Heading level 3 — sub-section</h3>
<h4>Heading level 4 — deeper sub-section</h4>
<h5>Heading level 5 — avoid unless strictly necessary</h5>
<h6>Heading level 6 — deepest level</h6>

## Heading utility classes

When you need the *visual style* of a heading level on a different element — for example, making an `<h2>` look like an `<h5>` without breaking the document outline — use the `.igd-h1` – `.igd-h6` and `.igd-p` utility classes.

| Class | Applies the visual style of |
|---|---|
| `.igd-h1` | `<h1>` |
| `.igd-h2` | `<h2>` |
| `.igd-h3` | `<h3>` |
| `.igd-h4` | `<h4>` |
| `.igd-h5` | `<h5>` |
| `.igd-h6` | `<h6>` |
| `.igd-p` | `<p>` (body text) |

```html
<!-- Semantically an h2, styled like an h5 -->
<h2 class="igd-h5">Section title that should appear smaller</h2>

<!-- A div that needs paragraph styling -->
<div class="igd-p">This text looks like a paragraph.</div>
```

Example:

<h2 class="igd-h5">An h2 styled with `.igd-h5`</h2>
<h3 class="igd-h2">An h3 styled with `.igd-h2`</h3>

## Body text

The `<p>` element represents a paragraph of text. In Markdown, any blank-line-separated block of text becomes a `<p>`.

A second paragraph follows immediately. Notice the consistent spacing between paragraphs applied by the documentation theme.

```md
A paragraph of body text — the most common block-level element for prose.

A second paragraph, separated from the first by a blank line.
```

## Inline text elements

Use these inside sentences to add meaning or visual emphasis.

| Element | Renders as | Use when |
|---|---|---|
| `<strong>` or `**text**` | <strong>Bold importance</strong> | Content has strong importance or urgency |
| `<b>` | <b>Bold without semantics</b> | Style-only bold, no extra meaning |
| `<em>` or `*text*` | <em>Emphasised text</em> | Stress emphasis that changes sentence meaning |
| `<i>` | <i>Italic without semantics</i> | Technical terms, foreign phrases, thoughts |
| `<u>` | <u>Underlined text</u> | Annotations, misspellings (non-link underline) |
| `<s>` or `~~text~~` | <s>Strikethrough</s> | Content no longer accurate or relevant |
| `<del>` | <del>Deleted content</del> | Editorial deletion (pairs with `<ins>`) |
| `<ins>` | <ins>Inserted content</ins> | Editorial insertion (pairs with `<del>`) |
| `<mark>` | <mark>Highlighted text</mark> | Highlighted / search result match |
| `<small>` | <small>Small print</small> | Side comments, legal text, fine print |
| `<sub>` | H<sub>2</sub>O | Subscript — chemical formulas, footnotes |
| `<sup>` | E=mc<sup>2</sup> | Superscript — exponents, ordinals |
| `<abbr title="Cascading Style Sheets">` | <abbr title="Cascading Style Sheets">CSS</abbr> | Abbreviations — shows expansion on hover |
| `<dfn>` | <dfn>Single-page application</dfn> | Defining instance of a term |
| `<time dateTime="2026-05-15">` | <time dateTime="2026-05-15">15 May 2026</time> | Machine-readable dates and times |
| `<a href>` | [this link](#) | Hyperlinks |
| `<a href target="_blank">` | <a href="https://www.infragistics.com" target="_blank" rel="noopener">Infragistics website</a> | External links — opens in a new tab, gets the external link icon |

```md
**Bold importance**, *emphasised text*, ~~strikethrough~~,
`inline code`, [link text](https://example.com)
```

```html
<strong>Bold importance</strong>, <b>bold without semantics</b>,
<em>emphasised</em>, <i>italic</i>, <u>underlined</u>, <s>strikethrough</s>,
<del>deleted</del> and <ins>inserted</ins> content, <mark>highlighted</mark>,
<small>small print</small>, H<sub>2</sub>O, E=mc<sup>2</sup>,
<abbr title="Cascading Style Sheets">CSS</abbr>, <dfn>a defined term</dfn>,
<time datetime="2026-05-15">15 May 2026</time>,
<a href="https://example.com" target="_blank" rel="noopener">an external link</a>
```

interactive documents</q>.</p>
