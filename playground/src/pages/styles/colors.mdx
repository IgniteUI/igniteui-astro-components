# Colors

Every colour comes from the Infragistics design system. This package carries a copy of it in `src/styles/design-system/`, and `DocsLayout` loads it before any other style. The same tokens serve the docs, the API docs, the blog and the marketing site.

## Read a semantic token

A semantic token is named for what the colour is for. It has one value in the light theme and one in the dark theme, and it switches by itself.

```css
.my-element {
  background: var(--igd-color-background-card);
  color: var(--igd-color-foreground-default);
  border: 1px solid var(--igd-color-border-default);
}
```

### Text

| For                   | Token                            | Sample                                                             |
| --------------------- | -------------------------------- | ------------------------------------------------------------------ |
| Headings              | `--igd-color-foreground-heading` | <span style="color: var(--igd-color-foreground-heading)">Aa</span> |
| Body text             | `--igd-color-foreground-default` | <span style="color: var(--igd-color-foreground-default)">Aa</span> |
| Supporting text       | `--igd-color-foreground-subtle`  | <span style="color: var(--igd-color-foreground-subtle)">Aa</span>  |
| Captions and meta     | `--igd-color-foreground-faint`   | <span style="color: var(--igd-color-foreground-faint)">Aa</span>   |
| Links and action text | `--igd-color-foreground-action`  | <span style="color: var(--igd-color-foreground-action)">Aa</span>  |

## Rules

- **Never read a palette step.** `var(--ig-gray-700)` is one fixed grey; it does not follow the theme and it says nothing about its purpose. Read `var(--igd-color-foreground-default)`.
- **Text in the action colour is `--igd-color-foreground-action`.** `--igd-color-background-action` is a fill; as text it can fall below the contrast minimum.
- **The label on a fill is its `-on` token**, `--igd-color-foreground-on-action` on `--igd-color-background-action`. It is black or white, whichever reads.
- **Feedback text sits on its own tint.** `--igd-color-background-error` is the background for `--igd-color-foreground-error`; the same for success, warning and info.
- **Hover and active colours are tokens too**, derived from their base. Do not darken a colour by hand.
- **No `light-dark()` pairs.** A token already has a value per theme.
- **When no token fits, do not pick a hex.** Say which token is missing; it is added in the design system.
