# Tables

**Markdown** tables are automatically wrapped in an accessible scroll container
(`.igd-table-wrapper`) by the `rehypeTableWrapper` plugin. The wrapper gives the
table a border, a sticky header row, and a sticky first column, and it scrolls
independently once the content grows past `--igd-table-max-height`.

Raw **HTML** `<table>` elements are **not** auto-wrapped — add the
`.igd-table-wrapper` yourself, as the expandable example below does.

---

## Standard table

Write a plain Markdown table. The header row pins to the top while scrolling vertically, and the first column pins to the left while scrolling horizontally.

```md
| Property   | Type      | Default | Description                       |
| ---------- | --------- | ------- | --------------------------------- |
| `value`    | `string`  | `""`    | Current value of the input field. |
| `disabled` | `boolean` | `false` | Disables the control.             |
```

| Property      | Type                             | Default    | Reflects | Description                                       |
| ------------- | -------------------------------- | ---------- | -------- | ------------------------------------------------- |
| `value`       | `string`                         | `""`       | no       | Current value of the input field.                 |
| `name`        | `string`                         | `""`       | yes      | Name of the control, submitted with the form.     |
| `label`       | `string`                         | `""`       | no       | Text label rendered above the input.              |
| `placeholder` | `string`                         | `""`       | no       | Placeholder shown while the field is empty.       |
| `disabled`    | `boolean`                        | `false`    | yes      | Disables the control and skips it on submit.      |
| `required`    | `boolean`                        | `false`    | yes      | Marks the field as required for validation.       |
| `readonly`    | `boolean`                        | `false`    | yes      | Makes the field non-editable but still focusable. |
| `outlined`    | `boolean`                        | `false`    | yes      | Renders the outlined visual variant.              |
| `size`        | `"small" \| "medium" \| "large"` | `"medium"` | yes      | Controls the density of the component.            |
| `invalid`     | `boolean`                        | `false`    | yes      | Reflects the current validation state.            |

---

## Expandable rows

Add `class="igd-table-expandable"` to a table to turn it into a disclosure table. Each record is a pair of rows — a **summary** row with a chevron toggle, immediately followed by a hidden **detail** row.

The toggle is CSS-only (a `:has()` selector — no JavaScript required) and works with <kbd>Space</kbd> when focused.

Each record is two rows. Repeat the `igd-row-summary` / `igd-row-detail` pair for every expandable record:

```html
<div class="igd-table-wrapper" role="region" aria-label="Expandable rows table" tabindex="0">
  <table class="igd-table-expandable">
    <thead>
      <tr>
        <th scope="col" aria-label="Expand row"></th>
        <th scope="col">Property</th>
        <th scope="col">Type</th>
        <th scope="col">Default</th>
      </tr>
    </thead>
    <tbody>
      <!-- Summary row: the toggle lives in the first cell -->
      <tr class="igd-row-summary">
        <td>
          <label class="igd-row-toggle">
            <input type="checkbox" aria-label="Toggle details for value" />
            <igc-icon name="chevron" collection="docs" class="igd-row-chevron"></igc-icon>
          </label>
        </td>
        <td><code>value</code></td>
        <td><code>string</code></td>
        <td><code>""</code></td>
      </tr>
      <!-- Detail row: hidden until the summary row's checkbox is checked -->
      <tr class="igd-row-detail">
        <td colspan="4">
          <div class="igd-row-detail-inner">The current value of the input.</div>
        </td>
      </tr>
    </tbody>
  </table>
</div>
```
