# Embedded Media

Reference for embedding video and audio in `.md` and `.mdx` files.

---

## YouTube embed — `<iframe>`

Uses the facade pattern: a thumbnail is shown first; the heavy YouTube `<iframe>` is only injected into the DOM when the user clicks play.

```html
<iframe
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="Video title"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
  allowfullscreen
  loading="lazy"
></iframe>
```

## Native video — `<video>`

```html
<video controls preload="metadata" poster="/img/poster.jpg">
  <source src="/media/clip.mp4" type="video/mp4" />
  <source src="/media/clip.ogg" type="video/ogg" />
  Your browser does not support the video element.
</video>
```

## Native audio — `<audio>`

```html
<audio controls preload="metadata">
  <source src="/media/clip.ogg" type="audio/ogg" />
  <source src="/media/clip.mp3" type="audio/mpeg" />
  Your browser does not support the audio element.
</audio>
```
