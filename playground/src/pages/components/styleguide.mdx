## Body text

The `<p>` element represents a paragraph of text. It is the
most common block-level element for prose content. Paragraphs are separated by
vertical margin and their line-height affects readability significantly.

A second paragraph follows immediately. Notice the consistent spacing between
paragraphs applied by the documentation theme. Long lines should wrap naturally
at the container boundary without any explicit `word-break` override
unless the content contains very long unbreakable strings.

<address>
  Written by <a href="mailto:docs@example.com">The Docs Team</a>.
  Visit us at <a href="#">igniteui.com</a>.
  — <code>&lt;address&gt;</code> element
</address>

## Inline text elements

| Element | Renders as | Use when |
|---|---|---|
| `<strong>` | <strong>Bold importance</strong> | Content has strong importance or urgency |
| `<b>` | <b>Bold without semantics</b> | Style-only bold, no extra meaning |
| `<em>` | <em>Emphasised text</em> | Stress emphasis that changes sentence meaning |
| `<i>` | <i>Italic without semantics</i> | Technical terms, foreign phrases, thoughts |
| `<u>` | <u>Underlined text</u> | Annotations, misspellings (non-link underline) |
| `<s>` | <s>Strikethrough</s> | Content no longer accurate or relevant |
| `<del>` | <del>Deleted content</del> | Editorial deletion (pairs with `<ins>`) |
| `<ins>` | <ins>Inserted content</ins> | Editorial insertion (pairs with `<del>`) |
| `<mark>` | <mark>Highlighted text</mark> | Highlighted / search result match |
| `<small>` | <small>Small print</small> | Side comments, legal text, fine print |
| `<sub>` | H<sub>2</sub>O | Subscript — chemical formulas, footnotes |
| `<sup>` | E=mc<sup>2</sup> | Superscript — exponents, ordinals |
| `<abbr title="Cascading Style Sheets">` | <abbr title="Cascading Style Sheets">CSS</abbr> | Abbreviations — shows expansion on hover |
| `<dfn>` | <dfn>Single-page application</dfn> | Defining instance of a term |
| `<time dateTime="2026-05-15">` | <time dateTime="2026-05-15">15 May 2026</time> | Machine-readable dates and times |
| `<a href>` | [this link](#) | Hyperlinks |
| `<span>` | <span style="color: var(--ig-primary-500)">Styled span</span> | Generic inline container for styling |

## Code & preformatted

| Element | Example | Use when |
|---|---|---|
| `<code>` | Use `console.log()` for debugging | Inline code snippets, file names, values |
| `<kbd>` | Press <kbd>Ctrl</kbd>+<kbd>K</kbd> to open search | Keyboard input or shortcuts |
| `<samp>` | Output: <samp>Error: connection refused on port 3000</samp> | Program or terminal output |
| `<var>` | The formula uses variable <var>x</var> as input | Mathematical or programming variables |
| `<pre>` + `<code>` | See fenced block below | Multi-line preformatted code |
| `<pre>` alone | See block below | Preformatted text without code semantics |

```ts
// <pre> + <code> — preformatted code block
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet('World')); // Hello, World!
```

<pre>Plain preformatted text without code semantics.
  Leading whitespace    is    preserved.
    Indentation is respected.
— &lt;pre&gt; alone</pre>

## Images

### Basic image — `<img>`

The `<img>` element embeds a raster or vector image. Always include
a descriptive `alt` attribute for accessibility.

<img
  src="https://picsum.photos/seed/igniteui/800/400"
  alt="A random placeholder landscape photo"
  width="800"
  height="400"
  style="max-width: 100%; height: auto; border-radius: 0.5rem; display: block;"
/>

### Responsive image — `<picture>` + `<source>`

The `<picture>` element wraps multiple `<source>` candidates.

<picture>
  <source media="(min-width: 800px)" srcSet="https://picsum.photos/seed/wide/1200/400" />
  <source media="(min-width: 400px)" srcSet="https://picsum.photos/seed/medium/800/400" />
  <img
    src="https://picsum.photos/seed/small/400/300"
    alt="A responsive placeholder image that changes by viewport width"
    width="800"
    height="400"
    style="max-width: 100%; height: auto; border-radius: 0.5rem; display: block;"
  />
</picture>

### Image with caption — `<figure>` + `<figcaption>`

<figure>

### Inline SVG — `<svg>`

SVG markup can be embedded directly in HTML. It scales losslessly and inherits
`currentColor` from the surrounding text.

<svg
  xmlns="http://www.w3.org/2000/svg"
  width="120"
  height="120"
  viewBox="0 0 24 24"
  fill="none"
  stroke="currentColor"
  strokeWidth="1.5"
  strokeLinecap="round"
  strokeLinejoin="round"
  aria-label="Inline SVG star icon"
  role="img"
  style="display: block; margin-block: 1rem; color: var(--sl-color-accent);"
>
  <polygon points="12 2 15.09 8.26 22 9.27 17 14.14 18.18 21.02 12 17.77 5.82 21.02 7 14.14 2 9.27 8.91 8.26 12 2"/>
</svg>

## Embedded media

### YouTube embed — `<iframe>`

Uses the **facade pattern**: a thumbnail image is shown first;
the heavy YouTube `<iframe>` is only injected into the DOM
when the user clicks play.

## HTML Character Entities

Common HTML named character references and how they render.

| Entity code | Renders as | Description |
|---|---|---|
| `&amp;` | & | Ampersand |
| `&lt;` | &lt; | Less-than sign |
| `&gt;` | &gt; | Greater-than sign |
| `&nbsp;` | (space) | Non-breaking space |
| `&mdash;` | — | Em dash |
| `&ndash;` | – | En dash |
| `&hellip;` | … | Ellipsis |
| `&ldquo;` / `&rdquo;` | " / " | Left / right double quotation marks |
| `&lsquo;` / `&rsquo;` | ' / ' | Left / right single quotation marks |
