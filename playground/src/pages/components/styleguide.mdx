## Body text

The `<p>` element represents a paragraph of text. It is the
most common block-level element for prose content. Paragraphs are separated by
vertical margin and their line-height affects readability significantly.

A second paragraph follows immediately. Notice the consistent spacing between
paragraphs applied by the documentation theme. Long lines should wrap naturally
at the container boundary without any explicit `word-break` override
unless the content contains very long unbreakable strings.

<address>
  Written by <a href="mailto:docs@example.com">The Docs Team</a>.<br />
  Visit us at <a href="#">igniteui.com</a>.<br />
  — <code>&lt;address&gt;</code> element
</address>

## Code & preformatted

Use `console.log()` for debugging — `<code>` for inline snippets.

Press <kbd>Ctrl</kbd>+<kbd>K</kbd> to open the search dialog — `<kbd>`
represents keyboard input.

The command returned <samp>Error: connection refused on port 3000</samp> —
`<samp>` for program output.

The formula uses variable <var>x</var> as input — `<var>`
for mathematical or programming variables.

```ts
// <pre> + <code> — preformatted code block
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet('World')); // Hello, World!
```

<pre>Plain preformatted text without code semantics.
  Leading whitespace    is    preserved.
    Indentation is respected.
— &lt;pre&gt; alone</pre>

## Images

### Basic image — `<img>`

The `<img>` element embeds a raster or vector image. Always include
a descriptive `alt` attribute for accessibility.

<img
  src="https://picsum.photos/seed/igniteui/800/400"
  alt="A random placeholder landscape photo"
  width="800"
  height="400"
  style="max-width: 100%; height: auto; border-radius: 0.5rem; display: block;"
/>

### Responsive image — `<picture>` + `<source>`

The `<picture>` element wraps multiple `<source>` candidates.

<picture>
  <source media="(min-width: 800px)" srcSet="https://picsum.photos/seed/wide/1200/400" />
  <source media="(min-width: 400px)" srcSet="https://picsum.photos/seed/medium/800/400" />
  <img
    src="https://picsum.photos/seed/small/400/300"
    alt="A responsive placeholder image that changes by viewport width"
    width="800"
    height="400"
    style="max-width: 100%; height: auto; border-radius: 0.5rem; display: block;"
  />
</picture>

### Inline SVG — `<svg>`

SVG markup can be embedded directly in HTML. It scales losslessly and inherits
`currentColor` from the surrounding text.

<svg
  xmlns="http://www.w3.org/2000/svg"
  width="120"
  height="120"
  viewBox="0 0 24 24"
  fill="none"
  stroke="currentColor"
  strokeWidth="1.5"
  strokeLinecap="round"
  strokeLinejoin="round"
  aria-label="Inline SVG star icon"
  role="img"
  style="display: block; margin-block: 1rem; color: var(--sl-color-accent);"
>
  <polygon points="12 2 15.09 8.26 22 9.27 17 14.14 18.18 21.02 12 17.77 5.82 21.02 7 14.14 2 9.27 8.91 8.26 12 2"/>
